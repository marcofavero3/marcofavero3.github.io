# Marco Favero Jr. · Portfólio

Portfólio em uma página: uma cidade isométrica em pixel art, à noite. Cada prédio é uma parte do currículo e acende quando o cursor chega perto.

Site: https://marcofavero3.github.io

## Arquivos

- `index.html`: a página inteira (HTML, CSS e JavaScript num arquivo só, sem dependências além das fontes do Google Fonts).
- `og.png`: imagem de prévia que aparece quando o link é compartilhado no LinkedIn e em outras redes.

## Publicar no GitHub Pages

1. Crie um repositório **público** chamado exatamente `marcofavero3.github.io`.
2. Envie `index.html`, `og.png` e este `README.md` para a branch `main`, na raiz.
3. Em **Settings → Pages**, confira se a origem está como **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Espere um ou dois minutos e abra https://marcofavero3.github.io.

Se o repositório tiver outro nome (por exemplo `portfolio`), o endereço vira `https://marcofavero3.github.io/portfolio/`. Nesse caso, troque as duas URLs das tags `og:url` e `og:image` no `index.html`.

## Divulgar no LinkedIn

- Use o endereço do site, não o do repositório: quem clica no repositório vê código, não a página.
- Antes de postar, cole o link no [Post Inspector](https://www.linkedin.com/post-inspector/) para o LinkedIn ler a imagem de prévia.
- Coloque o link também em **Em destaque** e em **Informações de contato → Site** do perfil.
